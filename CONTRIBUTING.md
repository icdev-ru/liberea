# Участие в разработке / Contributing

Спасибо, что хотите помочь! / Thanks for helping!

- **Ошибки и пожелания** — в [Issues](../../issues). Укажите версию, систему (Windows / Linux / Docker),
  что делали и что получилось; для ошибок приложите строки из окна сервера или журнала.
- **Код** — через Pull Request в ветку `main`. Перед отправкой:
  ```bash
  pip install -r requirements-dev.txt
  python -m pytest -q
  ```
- Стиль: Python 3.11+, без лишних зависимостей; интерфейс и сообщения — на русском.
- Не добавляйте в репозиторий книги, каталоги .inpx и другие материалы, защищённые авторским правом.

---

- **Bugs & ideas** — open an [Issue](../../issues): version, OS (Windows / Linux / Docker), steps, logs.
- **Code** — Pull Requests to `main`; run `python -m pytest -q` first.
- Python 3.11+, minimal dependencies; the UI is in Russian.
- Never commit books, .inpx catalogs or other copyrighted material.

Лицензия вклада — GPL-3.0, как и у проекта. / Contributions are licensed under GPL-3.0.
