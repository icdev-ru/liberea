# История изменений / Changelog

## 1.0.0

Первый публичный выпуск. / First public release.

- Три вида библиотек: папки «код Название (Автор)» с txt и обложкой; папка с файлами .txt/.fb2 (с подпапками,
  поиск дубликатов); коллекции INPX (каталоги MyHomeLib) — только метаданные, книги читаются из zip.
- Поиск по названию, автору, серии, коду и полному тексту (русский и английский, учёт словоформ), режимы
  «Автор» и «Серия» со списками, раздел «Жанры».
- Виды результатов: карточки, список, только обложки; тёмная и светлая тема.
- Скачивание TXT / PDF / FB2; личные подборки со сборкой одного PDF или FB2 с содержанием и обложками.
- Каталог OPDS 1.2 для читалок (FBReader, Moon+ Reader, KOReader…).
- Перевод английских книг на русский: локально (Argos / OPUS-MT, CTranslate2), Yandex Cloud
  или литературный — локальной языковой моделью (LM Studio, Ollama).
- Админка: сканирование, журнал импорта, правка книг, настройки в браузере, мастер первого запуска,
  защита входа от подбора пароля.
- Windows (портативная сборка), Linux (скрипт установки + systemd), Docker (amd64/arm64).
