## Установка

### Windows — портативная версия (рекомендуется)

1. Скачайте `Liberea-<версия>-windows-x64.zip` со страницы [Releases](../../../releases) и распакуйте,
   например, в `C:\Liberea`. Python ставить не нужно — он уже внутри.
2. Запустите `run.bat`. В окне появятся адреса, по которым открывается Либерея.
3. Откройте в браузере `http://localhost:5555/setup` — мастер первого запуска: пароль администратора и папки с книгами.
4. В админке нажмите **«Сканировать»** у нужной библиотеки.

### Windows — из исходников

Нужен Python 3.11+ с python.org (при установке отметьте «Add python.exe to PATH»).
Скачайте исходники и запустите `run.bat`: он сам создаст окружение `.venv` и установит пакеты (1–2 минуты, нужен интернет).

### Linux

```bash
tar xzf Liberea-<версия>-linux.tar.gz && cd Liberea-<версия>-linux
./packaging/linux/install.sh --service     # без --service — без автозапуска
```

Нужен Python 3.11+ (`sudo apt install python3 python3-venv`). С `--service` устанавливается служба systemd
`liberea` (автозапуск, перезапуск при сбое): `sudo systemctl status|restart liberea`, журнал — `journalctl -u liberea -f`.
Без службы запуск — `./packaging/linux/run.sh`.

### Docker

```bash
docker run -d --name liberea --restart unless-stopped -p 5555:5555 \
  -v "$PWD/data:/data" -v /srv/books:/books:ro ghcr.io/icdev-ru/liberea:latest
```

или `docker compose up -d` с файлом [`docker-compose.yml`](../docker-compose.yml). В томе `/data` — база, кеш,
настройки и модели перевода; книги монтируются только для чтения в `/books`, и в мастере первого запуска
папки указываются как `/books/...`. Образ есть для amd64 и arm64 (NAS, Raspberry Pi 4/5).

### Доступ с других устройств

Сервер по умолчанию слушает все сетевые адреса (`host = "0.0.0.0"`), открывайте `http://<IP компьютера>:5555`.
IP лучше закрепить за компьютером в настройках роутера (DHCP-резервация).

Windows: разрешите порт в брандмауэре (командная строка от администратора):
```
netsh advfirewall firewall add rule name="Liberea 5555" dir=in action=allow protocol=TCP localport=5555
```

> **Безопасность.** Либерея рассчитана на домашнюю сеть. Не открывайте её в интернет напрямую (проброс порта на роутере):
> в открытой части нет входа по паролю. Для доступа извне используйте VPN (WireGuard, Tailscale и т. п.).

### Автозапуск в Windows

Планировщик заданий, PowerShell от администратора (путь поправьте под свою папку):
```powershell
$a = New-ScheduledTaskAction -Execute "C:\Liberea\python\python.exe" -Argument "manage.py serve" -WorkingDirectory "C:\Liberea"
$t = New-ScheduledTaskTrigger -AtStartup
$s = New-ScheduledTaskSettingsSet -ExecutionTimeLimit 0 -RestartCount 3 -RestartInterval (New-TimeSpan -Minutes 1)
Register-ScheduledTask -TaskName "Liberea" -Action $a -Trigger $t -Settings $s -User "SYSTEM" -RunLevel Highest
```
Для версии из исходников вместо `python\python.exe` — `.venv\Scripts\python.exe`.
Остановить / запустить: `Stop-ScheduledTask Liberea; Start-ScheduledTask Liberea`.

### Обновление

Распакуйте новую версию поверх старой (папка `data` и `config.toml` не затрагиваются) и **перезапустите** Либерею.
Версия из исходников: после распаковки выполните `update.bat` (Linux — `install.sh`). Docker: `docker compose pull && docker compose up -d`.

## Настройка

Почти всё нужное задаётся в браузере: **Админка → Настройки** — название сайта, папки и названия библиотек,
включение/отключение частей, пароль. Изменения применяются сразу и хранятся в `data/settings.toml`.

Остальное — в `config.toml` (создаётся из `config.example.toml` при первом запуске; после правки — перезапуск):
адрес и порт, размеры страниц, формат PDF, перевод, расположение базы. Все параметры описаны в самом файле.

## Поиск

| Запрос | Что найдёт |
|---|---|
| `деревня любовь` | оба слова в любых формах: деревне, деревню, любовью… |
| `"в деревне"` | точную фразу (формы слов тоже учитываются) |
| `деревн*` | слова, начинающиеся с «деревн» |
| `мама -война` | «мама», но без «война» |
| `ab-421`, `AB-0421` | книгу по коду (ведущие нули не важны) |
| `mom мама` | русский и английский можно смешивать |

Переключатель **Везде / Название / Автор / Серия / Текст** выбирает, где искать. Буквы ё и е не различаются, регистр не важен.
Стемминг алгоритмический, поэтому неправильные формы не связываются (`любовь` не найдёт «любви») — используйте звёздочку: `люб*`.

Фильтры над результатами: **Библиотека** (если включено несколько частей), **Язык**, **Сортировка**.
Вид результатов: **Карточки** (с обложкой и фрагментом текста), **Списком** (одна строка на книгу) и **Только обложки**.
Выбранный вид запоминается.

На телефоне у книг есть кнопка **«Поделиться»** (файл или ссылка через системное меню). Передача файлов работает
только на защищённых адресах (https); в домашней сети по http можно поделиться ссылкой. В Chrome на Android это
обходится так: `chrome://flags/#unsafely-treat-insecure-origin-as-secure` → впишите адрес Либереи → Enabled.

## Авторы, серии, жанры

- **Автор** — поиск выдаёт список авторов с числом книг. Ищутся целые слова: `Васильев` найдёт Васильева и Васильеву,
  но не Василия; по началу слова — `Васил*` (если целым словом ничего нет, поиск сам повторится по началу слова).
  На странице автора — сначала книги по сериям (серии по алфавиту, внутри — по номеру), затем книги вне серий.
- **Серия** — поиск по началу слов: `Хоно` найдёт «Хонор Харрингтон». На странице серии — книги по номерам.
- **Жанры** (ссылка в шапке; есть, если подключена коллекция INPX) — разделы и поджанры по алфавиту с числом книг.
  В жанре книги показываются новые сначала или по алфавиту.
- Имена авторов, серии и жанры в карточках — ссылки на эти страницы.

## Подборки

- У каждого браузера свои подборки. Одна из них **активная** — кнопка «+ В подборку» добавляет книги в неё;
  её название и число книг видны в шапке.
- «+ Добавить все найденные» — сразу все результаты поиска (до 2000); на странице автора и серии — «все книги автора / серии».
- Книги в подборке можно перетаскивать: порядок = порядок в итоговом файле.
- **Собрать PDF / FB2** — один файл: титул, содержание со ссылками, обложки и тексты. Сборка идёт в фоне; готовые файлы кешируются.
- **✎ Изменить имя**, копия, очистка, удаление; **JSON** — сохранить подборку в файл и загрузить обратно (или передать другому).
- **Ваш ключ** («Мои подборки») — открыть свои подборки в другом браузере или после очистки cookie.

## Каталог OPDS для читалок

Адрес: `http://<IP компьютера>:5555/opds`. Добавьте его в читалке как сетевой каталог (FBReader: «Сетевая библиотека» →
«Добавить каталог»; Moon+ Reader: «Сетевые библиотеки» → «+»; CoolReader, KOReader, ReadEra — аналогично).

- поиск (значок лупы в читалке) — книги, авторы и серии;
- «Авторы» и «Серии» — указатель по буквам; у автора — книги по сериям и вне серий;
- «Жанры» и «Новые поступления»;
- у книги — обложка, описание и скачивание FB2 / PDF / TXT (и перевода, если он есть) прямо в библиотеку читалки.

Подборки, скрытые книги и отключённые части библиотеки в OPDS не показываются.

## Части библиотеки

Либерея объединяет до трёх источников. Любой можно не использовать, отключить или переименовать (Админка → Настройки).

### Основная библиотека

Папка, в которой каждая книга — подпапка с именем `код Название (Автор)`:
```
D:\Books\Library\
  ab-421 Summer Garden (J. X. Williams)\
      ab-421 Summer Garden.txt
      cover.jpg
```
Имена файлов внутри значения не имеют: берётся `*.txt` (самый большой, если их несколько) и картинка jpg/png/webp/gif/bmp.
Кодировка текста определяется автоматически (UTF-8, UTF-16, cp1251, KOI8-R, cp866, cp1252).
Повторное сканирование обрабатывает только новые и изменённые папки.

### Дополнительная библиотека

Папка со всеми подпапками, где **каждый файл .txt или .fb2 — отдельная книга**:
- название — имя файла (подчёркивания заменяются пробелами), автор — из FB2;
- **дубликаты** (одинаковые имена в .txt и .fb2, без учёта регистра и ё/е) — остаётся вариант с бо́льшим объёмом чистого текста;
  `dedup = "folder"` в `config.toml` — искать дубликаты только внутри одной папки;
- коды книг (`ex-00001`…) закрепляются навсегда; для FB2 «Скачать FB2» отдаёт оригинальный файл.

### Коллекция INPX

Каталог в формате MyHomeLib: файл `.inpx` и zip-архивы с книгами рядом с ним. Импортируются только метаданные
(автор, название, серия, жанр, язык, ключевые слова) — сотни тысяч книг за пару минут; тексты не индексируются,
книги читаются прямо из архивов, обложки извлекаются из FB2 при первом показе.

- **Новая версия коллекции:** положите новый `.inpx` (и новые архивы) на место старых и нажмите «Обновить из .inpx» —
  новые книги добавятся, изменённые обновятся, исчезнувшие удалятся. Повторный импорт без изменений — секунды.
- Отбор в `config.toml`, раздел `[inpx]`: `skip_deleted` (не брать удалённые), `langs` (только языки),
  `genres` / `exclude_genres` (только / кроме жанров).

## Перевод с английского на русский

На странице английской книги — кнопка **«Перевести»**. Перевод идёт в фоне (очередь переживает перезапуск).
Готовый перевод скачивается как TXT / PDF / FB2, **попадает в поиск** (английскую книгу можно найти русскими словами),
а в подборке есть галочка «переводы вместо оригиналов». В карточках переведённые книги помечены **RU**.
Администратор может поставить в очередь все найденные английские книги кнопкой над результатами поиска.

### Локальный перевод (бесплатно, без интернета)

1. `get-model.bat` (Linux: `.venv/bin/python manage.py get-model`) — скачает модель Argos Translate en→ru (~100 МБ).
   Если скачивание не проходит, скачайте `translate-en_ru-*.argosmodel` вручную и передайте путь к файлу той же команде.
2. Перезапустите Либерею.

Скорость — около 1500 знаков в секунду на современном процессоре (книга за пару минут).

**Модель покрупнее — OPUS-MT tc-big:** переводит заметно лучше, примерно втрое медленнее.
`manage.py get-model --opus-big` (скачает ~890 МБ и сконвертирует в ~250 МБ), затем в `config.toml`
`[translate] model_dir = "data/models/en_ru_big"`. Сравнить модели на одной книге:
`manage.py translate-test книга.txt --model data/models/en_ru_big`.

Другие варианты в `[translate]`: `engine = "yandex"` (Yandex Cloud, платно; нужны `yandex_api_key` и `yandex_folder_id`),
`allow = "admin"` — переводить может только администратор, `beam`, `threads`.

### Литературный перевод языковой моделью (LLM)

Второй, медленный вариант: локальная языковая модель переписывает перевод литературным языком
(помечается **RU★** и становится основным). Нужен OpenAI-совместимый сервер — [LM Studio](https://lmstudio.ai)
или [Ollama](https://ollama.com) — с моделью 7–12B в формате GGUF (Q4_K_M). На видеокарте с 12 ГБ памяти и больше —
десятки минут на книгу; на встроенной графике или процессоре — часы.

В `config.toml`: `[llm] enabled = true`, `url = "http://127.0.0.1:1234/v1"` (адрес сервера модели; это может быть
и другой компьютер в сети). Замер на вашем железе: `manage.py translate-test книга.txt --engine llm [--model имя]`.

## Админка

`/admin`: статистика, сканирование с прогрессом, журнал импорта (папки без txt, имена не по шаблону, дубликаты),
список книг с фильтрами и правкой названия / автора / кода, скрытие книг, очереди перевода, настройки.
Исправленные вручную данные не перезаписываются при сканировании; файлы на диске не меняются.

Пароль задаётся в мастере первого запуска и меняется в «Настройках». После 5 неудачных попыток входа подряд
вход временно блокируется. Забыли пароль — удалите строки `password_hash` и `password` из раздела `[admin]`
в `data/settings.toml` и перезапустите: снова откроется мастер первого запуска.

## Командная строка

`python manage.py …` (Windows-портативная: `python\python.exe manage.py …`; из исходников: `.venv\Scripts\python.exe manage.py …`):

| Команда | Что делает |
|---|---|
| `serve` | запустить сервер |
| `scan [--force]` | сканировать основную библиотеку (`--force` — всё заново) |
| `scan --extra [--force]` | дополнительную библиотеку |
| `scan --inpx [--force]` | импорт / обновление коллекции INPX |
| `get-model [файл]`, `get-model --opus-big [архив]` | модели перевода |
| `translate-test книга.txt [--chars N] [--model …] [--engine llm]` | замер скорости и качества перевода |
| `translate --all-en` | поставить в очередь перевод всех английских книг |
| `hash-password` | хеш пароля для `config.toml` |
| `stats` | краткая статистика |

## Как устроено

- **Python + FastAPI**, один процесс, без отдельного сервера базы данных.
- **SQLite** (`data/library.db`): книги, подборки, журнал, переводы. Полнотекстовый индекс FTS5 хранит только основы слов
  (стеммер Snowball: русский для кириллицы, английский для латиницы); сами тексты остаются в папках библиотеки.
  10 000 книг (~900 МБ текста) → база ~300 МБ; 600 000 записей INPX → ~450 МБ.
- PDF собирается fpdf2 со шрифтом DejaVu Serif (папка `fonts`, свободная лицензия); FB2 — стандартной библиотекой.
- Кеш (`data/cache`): миниатюры обложек, готовые PDF/FB2, тексты FB2. Его можно удалить в любой момент
  (кнопка «Очистить кеш» в админке).

## Резервная копия

Копируйте папку `data`: база (с подборками и правками), переводы, настройки. Индекс всегда можно пересоздать сканированием,
подборки и переводы — нет.
